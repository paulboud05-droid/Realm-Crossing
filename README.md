# Pocket Island

An original cozy island-life game that runs in your browser on desktop and phone.

**Play:** open the GitHub Pages link for this repo. On iPhone, tap Share, then Add to Home Screen.

- Desktop: WASD to move, Space to act, and H shows the controls.
- Phone: joystick on the left, with A/B/Tools buttons on the right. Landscape works best.
- Progress saves in your browser. Use Settings, then Export save, to keep a backup code.
